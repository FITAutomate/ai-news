# Repo Skills

This folder stores repository-specific Desktop Commander skills for `ai-news`.

## Available Skills

- `ai-news-weekly`
  - Path: `skills/ai-news-weekly/SKILL.md`
  - Purpose: Create, validate, and publish weekly AI News Pulse updates.

## Weekly Run

1. Open this repo: `D:\DesktopCommander\ai-news`
2. Trigger the skill by request, for example:
   - "Use ai-news-weekly to create Week 15 and publish"
3. Confirm the final commit/push output.

## Notes

- Skill artifacts are versioned with this repo.
- Validation script for news JSON is in `skills/ai-news-weekly/scripts/validate-news-json.mjs`.
