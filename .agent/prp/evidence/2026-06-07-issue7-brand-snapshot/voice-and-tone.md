# FIT Brand — Voice and tone

## Detailed writing audit

Use `brand/anti-ai-writing-style.md` as the detailed writing audit rule for
voiced FIT content. This file defines the brand voice. The anti-AI writing
style file defines the editing pass that keeps that voice from sounding generic,
inflated, or machine-written.

## The six attributes

### 1. Practical
Write about what things actually do, not what they could theoretically become.
- ✓ "FIT Docs Lite gives your team a searchable, publishable documentation site."
- ✗ "FIT Docs Lite transforms how your organisation thinks about knowledge."

### 2. Clear
One idea per sentence. No jargon without definition. No padding.
- ✓ "We handle the technical setup. You focus on the content."
- ✗ "By leveraging our comprehensive implementation methodology, we enable clients
     to focus on their core value-creation activities."

### 3. Structured
Information has a hierarchy. The most important thing comes first.
- ✓ Lead with the outcome. Follow with how. End with what's next.
- ✗ Bury the point in qualifications.

### 4. Trustworthy
Say what you can do. Say what you can't. Don't oversell.
- ✓ "FIT Docs Pro includes the publish pipeline. Premium adds agent assistance —
     that tier is currently in testing."
- ✗ "Our powerful AI handles everything automatically."

### 5. Automation-first
The default assumption is that things should run without manual intervention.
- ✓ "Once configured, the system promotes documents without you touching it."
- ✗ "You can use this to help automate some of your processes if you want."

### 6. Premium through precision
Quality is communicated by exactness, not decoration.
- ✓ Specific numbers, specific outcomes, specific steps.
- ✗ Vague superlatives: "best-in-class", "enterprise-grade", "world-class".

## Words we don't use

| Avoid | Replace with |
|-------|-------------|
| Revolutionary | Practical |
| Game-changing | Effective |
| Leverage (as a verb) | Use |
| Cutting-edge | Current |
| Seamless | Straightforward |
| Robust | Reliable |
| Synergy | — (just don't) |
| Going forward | From here |
| In order to | To |
| It is important to note that | — (just say it) |

## Tone by context

| Context | Tone |
|---------|------|
| Marketing copy | Confident, direct, outcome-focused |
| Documentation | Precise, instructional, no ambiguity |
| Error messages | Clear, non-blaming, actionable |
| Agent responses | Structured, honest, surfaces gaps |
| Proposals | Professional, specific, no fluff |
