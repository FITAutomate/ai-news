# FIT Brand — Typography

## Font stack

| Role     | Font       | Weights used | Fallback |
|----------|------------|--------------|---------|
| Headings | Poppins    | 500, 600     | sans-serif |
| Body     | Open Sans  | 400, 600     | sans-serif |
| Mono     | JetBrains Mono | 400     | monospace |

## Type scale

| Level | Size  | Weight | Font      | Usage |
|-------|-------|--------|-----------|-------|
| h1    | 48px  | 600    | Poppins   | Hero headlines only |
| h2    | 36px  | 600    | Poppins   | Section headings |
| h3    | 24px  | 500    | Poppins   | Sub-section headings |
| h4    | 20px  | 500    | Poppins   | Card titles, labels |
| body  | 16px  | 400    | Open Sans | All body copy |
| small | 14px  | 400    | Open Sans | Captions, metadata |
| mono  | 14px  | 400    | JetBrains | Code, technical strings |

## Line height

- Headings: 1.2
- Body: 1.7
- Captions: 1.5

## Rules

- Never use font weights outside the defined stack.
- Heading hierarchy must be respected — no skipping levels.
- Do not use Open Sans for headings or Poppins for body copy.
- Minimum body text size: 14px. Never smaller in any client deliverable.
