# `.agent/prp/prds/`

Product Requirement Prompts (PRDs). One file per PRP, named
`YYYY-MM-DD-<slug>.prd.md`.

The PRD is the authoritative brief for a planned scope of work. It captures purpose, current state,
scope (in / out), acceptance criteria, and references. A PRD does not begin execution; execution
flows through linked plans, issues, and PRs under `.agent/prp/plans/` and `.agent/prp/issues/`.
