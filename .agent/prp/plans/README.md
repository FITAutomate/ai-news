# `.agent/prp/plans/`

Implementation plans and issue maps derived from PRDs. One file per plan, named
`YYYY-MM-DD-<slug>.md`.

A plan decomposes a PRD into concrete, sequenced issues with acceptance criteria, validation
commands, rollback boundaries, and human approval gates. A plan is reviewed before the issues it
proposes are created on the repo.

Current plans:

- `2026-06-06-ai-news-implementation-issue-map.md` -- proposed implementation issue
  map for the AI News Astro + FIT brand + Cloudflare Pages migration.
